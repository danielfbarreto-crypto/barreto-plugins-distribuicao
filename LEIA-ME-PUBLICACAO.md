# Regras desta central

- Publicar documentação de uso, imagens aprovadas e instaladores conferidos; manter fontes de manutenção e ferramentas administrativas no repositório próprio.
- Uma pasta por plugin; uma release por plugin/versão, com nome e status claros.
- Não usar /releases/latest como referência única para todos os plugins. Cada catálogo aponta a sua versão.
- Preservar o ZIP aprovado sem recompor a partir de versões antigas; conferir hash antes de anexar.
- Nunca publicar licença do servidor, chave privada, segredo compartilhado, dados de clientes ou projetos RVT.
- Guias vinculados devem corresponder às versões funcionais registradas. Identificar complementos comuns da distribuição.
- Homologação permanece pré-release até aprovação; não renumerar nem promover por conveniência.
- Esta central é pública desde 09/11/2026 para consulta e download, sem conceder edição dos arquivos oficiais. O repositório de manutenção continua privado. A autorização do plugin pela rede/VPN é independente do download.
- Repositórios pessoais privados têm limitações de papéis: não prometer acesso somente de leitura sem verificar as permissões disponíveis. Para gestão por equipes e papéis separados, avaliar organização GitHub antes de convidar usuários.
