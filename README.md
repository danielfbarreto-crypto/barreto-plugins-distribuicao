## Comece por aqui

1. Abra a página do plugin e confira se a versão está **Liberada** ou **Homologação**.
2. Abra **Baixar distribuição** e escolha o ZIP do plugin em **Assets**. Os arquivos automáticos **Source code** não são instaladores.
3. Extraia todo o ZIP, feche o Revit após tratar seus trabalhos e execute o BAT indicado.
4. Abra o Revit 2025 e siga o manual A4 ou mobile da função.

## Acesso e versões

Desde 09/11/2026, esta central é pública: qualquer pessoa pode consultar os manuais e baixar os pacotes, sem convite. Isso não concede permissão para alterar os arquivos oficiais nem substitui a autorização de uso do plugin pela rede/VPN Barreto. Uma publicação não atualiza os computadores automaticamente: baixe e instale a versão indicada.

**Homologação** significa teste controlado antes da liberação geral. **Liberada** será usada somente após aprovação expressa e conferência. Uma versão de plugin não substitui a de outro; sempre consulte seu catálogo.

Esta central mantém documentação de uso e pacotes de instalação. As fontes de manutenção, testes e ferramentas administrativas permanecem no repositório de manutenção restrito. Os pacotes pyRevit contêm os scripts necessários à execução; essa separação não torna o código local inviolável.
